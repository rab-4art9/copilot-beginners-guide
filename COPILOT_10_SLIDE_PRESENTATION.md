## SLIDE 5: How to Prompt Like a Pro

### ❌ Bad Prompts
- "Fix it."
- "Make this better."
- "Write an app."

### ✅ Good Prompts
- "Write a Python function that calculates the average of a list"
- "Explain this JavaScript code line by line for beginners"
- "Refactor this to be simpler with comments"

### The Prompt Formula
1. **What?** (be specific)
2. **What language?** (Python, JavaScript, etc.)
3. **What format?** (function, class, HTML)
4. **What constraints?** (simple, fast, comments)
5. **Why?** (optional)

### Example
**Bad:** "Make a website"
**Good:** "Create a simple 3-page portfolio website in HTML/CSS with:
- Home page with introduction
- Projects page with gallery
- Contact form
- Mobile-friendly design
- Dark theme"

**Step 1: Ask for Template**
```
"Write a simple to-do app in JavaScript"
```

**Step 2: Review Code**
- Read every line
- Ask: "What does this line do?"

**Step 3: Ask for Tests**
```
"Write tests for the add function"
```

**Step 4: Modify Yourself**
- Change colors
- Add features
- Break things to learn

**Step 5: Explain What You Built**
- You should be able to explain every line
- If you can't, ask Copilot to explain

## SLIDE 7: Common Mistakes & How to Avoid Them

### The 5 Most Common Beginner Mistakes

**❌ Mistake 1:** Copy code without understanding
✅ **Fix:** Read it and ask Copilot to explain

**❌ Mistake 2:** Ask vague questions
✅ **Fix:** Be specific with examples

**❌ Mistake 3:** Don't test code
✅ **Fix:** Always run it first with test cases

**❌ Mistake 4:** Paste private data
✅ **Fix:** Never share passwords or keys with AI

**❌ Mistake 5:** Expect perfect output
✅ **Fix:** Treat AI output as a starting point

## SLIDE 8: Security & Responsibility

### Before Using AI-Generated Code, Ask:

- ✅ Is this code secure?
- ✅ Does it validate inputs?
- ✅ Does it handle errors?
- ✅ Am I allowed to use this?
- ✅ Can I explain every line?

### Never Paste Into AI Tools:
🔒 Passwords
🔒 Private keys
🔒 Credit card numbers
🔒 Personal information
🔒 Medical data

### Remember
You are responsible for the code in your project.
You must understand it.
You must maintain it.

## SLIDE 9: The Mindset for Success

### This is NOT Cheating
Modern developers use AI tools. It's expected.
The difference:
- Beginners use AI to learn faster
- Professionals use AI to focus on harder problems
- Both review and verify output

### The Golden Rules

**Rule 1: Understand Before Using**
If you can't explain it, don't use it.

**Rule 2: Test Everything**
Every function, every component, every feature.

**Rule 3: Use AI to Learn**
Ask Copilot to explain code you don't understand.

**Rule 4: Think Critically**
Don't blindly trust AI suggestions.

**Rule 5: Keep Learning**
Use AI as a tool, not a replacement for learning.
